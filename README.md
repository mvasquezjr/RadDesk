# RadDesk

A browser-based radiography student toolkit.

## Current tools
- Exposure Playground with editable case values
- Cause → Effect relationship trainer
- Formula Solver
- Positioning Reference
- Expanded Terminology reference (253 study concepts)
- Expanded Abbreviations reference (308 entries)
- Learning Library with 100 curated external educational resources and search/filtering
- Autosaved Scratchpad
- Local browser autosave + manual checkpoints

## Files
- `index.html` — application layout
- `styles.css` — interface styling
- `reference-data.js` — terminology, abbreviations, and curated learning library
- `app.js` — application behavior and calculators


## V2 additions
- Universal Search (Ctrl/Cmd + K) across tools, 72 positioning entries, terminology, abbreviations, troubleshooting entries, and 100 learning resources
- Expanded Positioning Reference with region filtering, CR/SID, positioning, breathing, structures demonstrated, evaluation criteria, and pitfalls
- Radiograph Troubleshooter with 25 common image-quality/positioning problems
- Favorites and Recently Viewed panels persisted in local browser storage
- `student-tools-data.js` contains positioning and troubleshooting data
